# Shotta 用户指南

Shotta 是一款在 macOS 菜单栏运行的截图工具。你可以截取整个屏幕、区域、窗口或可见 UI 元素，然后在编辑器中编辑图片，或将其保存为 PNG 文件。

## 打开图像与另存为

通过**文件 > 打开图像…**（Command+O）、菜单栏、Finder 的**打开方式 > Shotta**，或将文件拖入编辑器，可以打开 PNG、JPEG、WebP、HEIC/HEIF、TIFF、BMP 和 GIF。多个文件按顺序加入历史记录。动画或多页图像仅打开第一帧或第一页。超过 6400 万像素或 256 MiB 解码数据的图像无法打开。打开文件无需屏幕录制权限，也不会触发截图自动保存。

通过**文件 > 另存为…**（Shift+Command+S）或右键点击保存按钮，可以选择文件夹、文件名和 PNG/JPEG/TIFF/HEIC/BMP 格式。PNG 和 TIFF 保留透明度，JPEG、HEIC 和 BMP 使用白色背景。WebP 仅支持打开。替换已有文件前，系统会要求确认。

Command+S 和正常点击保存按钮仍会在设置的文件夹中创建新的 PNG。导入不会修改源文件。只有在另存为时选择源文件并确认替换，才会覆盖源文件。


## 开始使用

1. 启动 `Shotta.app`。
2. 确认 macOS 菜单栏右侧出现 Shotta 图标。
3. 第一次截图时，如果 macOS 请求屏幕录制权限，请允许。
4. 使用元素截图时，如果出现辅助功能权限提示，请点击 `打开系统设置` 并允许 Shotta。

如果 macOS 在首次启动时以"无法验证的应用"警告拦截，请打开 `系统设置` > `隐私与安全性`，然后点击 `仍要打开`。详情请参阅 [README](../README.md)。

Shotta 是菜单栏应用。启动后不会立即打开大型主窗口，请通过菜单栏或全局快捷键开始截图。

## 基本截图

点击菜单栏中的 Shotta 图标，可以使用以下命令。

| 菜单 | 默认快捷键 | 操作 |
| --- | --- | --- |
| 区域截图 | `Control + Option + Shift + 4` | 截取拖拽出的矩形区域。 |
| 全屏截图 | `Control + Option + Shift + 3` | 截取你点击的显示器。 |
| 窗口截图 | `Control + Option + Shift + 5` | 截取指针下方高亮的窗口。 |
| 元素截图 | `Control + Option + Shift + 6` | 截取指针下方高亮的 UI 元素。 |

截图覆盖层打开时：

| 按键或操作 | 说明 |
| --- | --- |
| `Space` | 按全屏、区域、窗口、元素的顺序切换模式。 |
| `Esc` | 取消截图并关闭覆盖层。 |
| 拖拽 | 在区域截图模式中选择范围。 |
| 点击 | 在全屏、窗口或元素模式中截取当前高亮目标。 |

在多显示器环境中，Shotta 会在所有显示器上显示覆盖层。全屏截图以你点击的显示器为准，区域截图可以跨越显示器边界。

## 元素截图权限

元素截图使用 macOS 辅助功能权限来检测指针下方的按钮、输入框、列表行等 UI 元素。

如果缺少权限，Shotta 会显示权限提示。点击 `打开系统设置`，然后在 `隐私与安全性` > `辅助功能` 中允许 Shotta。授权后如果元素仍未高亮，请退出并重新启动 Shotta。

元素截图基于当前屏幕上可见的辅助功能元素区域。它不会自动截取整个网页或屏幕外的隐藏 DOM 内容。

## 截图后操作

默认情况下，截图完成后 Shotta 会打开编辑器。你可以在设置中将截图后操作改为直接复制到剪贴板。此模式下，Shotta 会复制截图并显示短暂的完成提示。

从菜单栏菜单选择 `打开编辑器`，可以重新打开最近一次截图或当前编辑器。

## 编辑器

使用工具栏编辑图片。你可以在设置中将工具栏放在左侧、顶部或底部。

| 工具 | 说明 |
| --- | --- |
| 复制 | 将当前编辑结果复制到剪贴板。 |
| 保存 | 将当前编辑结果保存为 PNG 文件。 |
| 撤销 / 重做 | 撤销或重新应用编辑。 |
| 选择 | 选择、移动和调整现有标注。 |
| 矩形 / 椭圆 / 箭头 / 直线 | 在图片上绘制形状。 |
| 画笔 | 自由绘制线条。 |
| 高亮 | 添加高亮标记。 |
| 文本 | 在图片上添加文本。 |
| 裁剪 | 只保留选定区域。 |
| 模糊 | 对选定区域应用模糊或马赛克。 |

根据当前工具或选中对象，你可以调整颜色、线宽、文字大小、效果类型和效果强度。复制和保存会使用当前可见的编辑结果。

## 实况文本

选择工具处于激活状态时，Shotta 会识别当前截图中的文字。在图片上的文字处拖拽即可选中，然后按 `Command + C` 复制选中的文字而不是图片。按 `Esc` 或切换到其他工具即可取消文字选择。

文字识别完全在设备上进行。如果无法选中任何内容，可能是截图中没有可识别的文字。

## 历史记录

编辑器历史面板最多保留 100 个最近截图。点击缩略图可切换到其他截图。

历史面板打开时：

| 操作 | 说明 |
| --- | --- |
| `Option + Up` | 移动到更新的截图 |
| `Option + Down` | 移动到更早的截图 |
| `Option + 鼠标滚轮` | 浏览历史项目 |
| 右键缩略图 | 显示复制、显示保存位置和删除操作 |

对于已保存文件的历史项目，右键菜单可以显示保存位置。

## 设置

通过 Shotta 菜单栏图标或 `Command + ,` 打开设置。

### 通用

| 项目 | 说明 |
| --- | --- |
| 截图文件夹 | 保存和自动保存的默认文件夹。 |
| 自动保存 | 每次截图时自动保存 PNG 文件。 |
| 登录时启动 | 登录 macOS 时自动启动 Shotta。 |
| 语言 | 选择英语、韩语、中文或日语。 |
| 截图后操作 | 打开编辑器或直接复制到剪贴板。 |
| 工具栏位置 | 将编辑器工具栏放在左侧、顶部或底部。 |

自动保存文件名使用 `shotta-YYYYMMDD-HHMM.png` 格式。如果同一分钟内创建多个文件，Shotta 会附加编号，例如 `shotta-YYYYMMDD-HHMM 2.png`。

### 快捷键

在快捷键标签页中，可以更改全屏、区域、窗口和元素截图的全局快捷键。点击快捷键字段，输入新的组合键即可保存。点击重置按钮可恢复默认快捷键。

如果其他应用或 macOS 已使用同一个全局快捷键，Shotta 可能无法注册该快捷键。若某个快捷键没有响应，请选择其他组合。

## 故障排除

### 截图为黑屏或空白

在 `系统设置` > `隐私与安全性` > `屏幕录制` 中检查权限，允许 Shotta 后重新启动应用。

### 元素截图无法选择任何内容

检查辅助功能权限。部分应用会限制辅助功能信息，密码输入框等安全输入区域可能无法作为元素截图目标。

### 快捷键无响应

检查设置中的快捷键标签页。其他应用可能已经占用了相同的全局快捷键。

### Shotta 一直请求权限

开发构建或 ad-hoc 签名的应用在每次重新构建后，可能会被 macOS 识别为不同应用。使用相同的 bundle identifier 和签名 identity 可以减少重复权限提示。

### 完全退出 Shotta

点击菜单栏中的 Shotta 图标，然后选择 `退出`。只关闭编辑器窗口时，Shotta 仍会在菜单栏中运行。

## 卸载

1. 点击菜单栏中的 Shotta 图标并选择 `退出`。
2. 从 Applications 文件夹删除 `Shotta.app`。
3. 如需删除设置，在终端运行 `defaults delete com.local.Shotta`。
4. 可在 `系统设置` > `隐私与安全性` > `屏幕录制` 和 `辅助功能` 中移除 Shotta 条目。

已保存或自动保存的截图是普通 PNG 文件，会保留在你指定的文件夹中。
