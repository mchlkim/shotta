# Shotta 사용자 가이드

Shotta는 macOS 상단바에서 실행되는 스크린샷 도구입니다. 전체 화면, 영역, 창, 화면 요소를 빠르게 캡처하고, 캡처한 이미지를 에디터에서 편집하거나 PNG 파일로 저장할 수 있습니다.

## 시작하기

1. `Shotta.app`을 실행합니다.
2. macOS 상단바 오른쪽에 Shotta 아이콘이 표시되는지 확인합니다.
3. 처음 캡처할 때 macOS가 화면 기록 권한을 요청하면 허용합니다.
4. 요소 캡처를 사용할 때 손쉬운 사용 권한 안내가 표시되면 `시스템 설정 열기`를 눌러 Shotta를 허용합니다.

Shotta는 일반 창 앱이 아니라 상단바 앱입니다. 앱을 실행해도 큰 메인 창이 바로 열리지 않으며, 상단바 메뉴나 전역 단축키로 캡처를 시작합니다.

## 기본 캡처

상단바의 Shotta 아이콘을 클릭하면 다음 메뉴를 사용할 수 있습니다.

| 메뉴 | 기본 단축키 | 동작 |
| --- | --- | --- |
| 영역 캡처 | `Control + Option + Shift + 4` | 드래그한 사각형 영역을 캡처합니다. |
| 전체 화면 캡처 | `Control + Option + Shift + 3` | 클릭한 디스플레이 전체를 캡처합니다. |
| 창 캡처 | `Control + Option + Shift + 5` | 커서 아래 하이라이트된 창을 캡처합니다. |
| 요소 캡처 | `Control + Option + Shift + 6` | 커서 아래 하이라이트된 UI 요소를 캡처합니다. |

캡처 오버레이가 열린 상태에서 사용할 수 있는 조작입니다.

| 키 또는 동작 | 설명 |
| --- | --- |
| `Space` | 전체 화면, 영역, 창, 요소 순서로 모드를 전환합니다. |
| `Esc` | 캡처를 취소하고 오버레이를 닫습니다. |
| 드래그 | 영역 캡처 모드에서 캡처할 범위를 지정합니다. |
| 클릭 | 전체 화면, 창, 요소 캡처 모드에서 현재 하이라이트된 대상을 캡처합니다. |

멀티 모니터 환경에서는 모든 디스플레이 위에 오버레이가 표시됩니다. 전체 화면 캡처는 클릭한 모니터를 기준으로 동작하고, 영역 캡처는 모니터 경계를 넘어 드래그할 수 있습니다.

## 요소 캡처 권한

요소 캡처는 버튼, 입력칸, 목록 행처럼 커서 아래의 UI 요소를 감지하기 위해 macOS 손쉬운 사용 권한을 사용합니다.

권한이 없으면 Shotta가 안내 창을 표시합니다. `시스템 설정 열기`를 누른 뒤 `개인정보 보호 및 보안` > `손쉬운 사용`에서 Shotta를 허용하세요. 권한을 부여한 뒤에도 요소가 하이라이트되지 않으면 Shotta를 종료했다가 다시 실행합니다.

요소 캡처는 현재 화면에 보이는 접근성 요소의 영역을 기준으로 캡처합니다. 화면 밖으로 스크롤해야 보이는 전체 웹페이지나 전체 DOM 요소를 자동으로 이어 붙이는 기능은 아닙니다.

## 캡처 후 동작

기본 설정에서는 캡처가 끝나면 에디터 창이 열립니다. 설정에서 캡처 후 동작을 `클립보드에 복사`로 바꾸면 캡처 결과를 바로 클립보드에 복사하고 짧은 완료 표시만 보여줍니다.

상단바 메뉴의 `에디터 열기`를 선택하면 마지막 캡처 결과 또는 현재 에디터를 다시 열 수 있습니다.

## 에디터

에디터에서는 왼쪽 또는 상단 툴바에서 도구를 선택해 이미지를 편집합니다. 툴바 위치는 설정에서 바꿀 수 있습니다.

| 도구 | 설명 |
| --- | --- |
| 복사 | 현재 편집 결과를 클립보드에 복사합니다. |
| 저장 | 현재 편집 결과를 PNG 파일로 저장합니다. |
| 실행 취소 / 다시 실행 | 편집 작업을 되돌리거나 다시 적용합니다. |
| 선택 | 기존 주석을 선택, 이동, 크기 조절합니다. |
| 사각형 / 원 / 화살표 / 선 | 이미지 위에 도형을 그립니다. |
| 펜 | 자유롭게 선을 그립니다. |
| 하이라이트 | 강조 표시를 그립니다. |
| 텍스트 | 이미지 위에 텍스트를 추가합니다. |
| 자르기 | 선택한 영역만 남기도록 이미지를 자릅니다. |
| 흐림 | 선택한 영역에 블러 또는 모자이크 효과를 적용합니다. |

도형, 펜, 하이라이트, 텍스트, 흐림 효과는 선택 상태에 따라 색상, 굵기, 글자 크기, 효과 종류, 효과 강도 같은 세부 옵션을 조정할 수 있습니다. 저장 또는 복사할 때는 현재 보이는 편집 결과가 반영됩니다.

## 에디터 단축키

| 단축키 | 동작 |
| --- | --- |
| `Command + C` | 편집 결과 복사 |
| `Command + S` | 편집 결과 저장 |
| `Command + Z` | 실행 취소 |
| `Command + Shift + Z` 또는 `Command + Y` | 다시 실행 |
| `Command + +` | 확대 |
| `Command + -` | 축소 |
| `Space` | 화면 맞춤 위치로 되돌리기 |
| `Esc` | 현재 도구 또는 선택 작업 취소 |
| `Return` | 자르기 선택 확정 |
| `Delete` | 선택한 주석 삭제 |
| `Command + A` | 모든 주석 선택 |
| `Command + W` | 에디터 창 닫기 |
| `Command + ,` | 설정 열기 |

도구 선택 단축키입니다.

| 키 | 도구 |
| --- | --- |
| `R` | 사각형 |
| `O` | 원 |
| `A` | 화살표 |
| `D` | 펜 |
| `H` | 하이라이트 |
| `T` | 텍스트 |
| `C` | 자르기 |
| `B` | 흐림 |

선택한 도형이나 효과의 값은 다음 단축키로 빠르게 조정할 수 있습니다.

| 단축키 | 동작 |
| --- | --- |
| `Option + +` | 선택한 선 굵기 또는 흐림 강도 증가 |
| `Option + -` | 선택한 선 굵기 또는 흐림 강도 감소 |

## 히스토리

에디터의 히스토리 패널에는 최근 캡처가 최대 100개까지 유지됩니다. 썸네일을 클릭하면 이전 캡처로 전환할 수 있습니다.

히스토리 패널이 열린 상태에서는 다음 조작을 사용할 수 있습니다.

| 조작 | 설명 |
| --- | --- |
| `Option + Up` | 더 최근 캡처로 이동 |
| `Option + Down` | 더 이전 캡처로 이동 |
| `Option + 마우스 휠` | 히스토리 항목 이동 |
| 썸네일 우클릭 | 이미지 복사, 저장 위치 열기, 삭제 메뉴 표시 |

저장된 파일이 있는 히스토리 항목은 우클릭 메뉴에서 저장 위치를 열 수 있습니다.

## 설정

상단바 Shotta 아이콘 또는 `Command + ,`로 설정을 엽니다.

### 일반

| 항목 | 설명 |
| --- | --- |
| 스크린샷 폴더 | 저장과 자동 저장에 사용할 기본 폴더입니다. |
| 자동 저장 | 캡처할 때마다 PNG 파일을 자동 저장합니다. |
| 자동 시작 | macOS 로그인 시 Shotta를 자동 실행합니다. |
| 언어 | 영어, 한국어, 중국어, 일본어 중 앱 UI 언어를 선택합니다. |
| 캡처 후 동작 | 캡처 후 에디터를 열지, 클립보드에 바로 복사할지 선택합니다. |
| 툴바 위치 | 에디터 툴바를 좌측 또는 상단에 배치합니다. |

자동 저장 파일 이름은 `shotta-YYYYMMDD-HHMM.png` 형식입니다. 같은 분에 여러 파일이 생기면 `shotta-YYYYMMDD-HHMM 2.png`처럼 번호가 붙습니다.

### 단축키

단축키 탭에서는 전체 화면, 영역, 창, 요소 캡처의 전역 단축키를 바꿀 수 있습니다. 각 행의 단축키 필드를 클릭한 뒤 새 조합을 입력하면 저장됩니다. 되돌리기 버튼을 누르면 해당 단축키가 기본값으로 복원됩니다.

다른 앱이나 macOS 시스템 단축키와 충돌하는 조합은 등록되지 않을 수 있습니다. 단축키가 동작하지 않으면 설정에서 다른 조합으로 바꿔보세요.

## 문제 해결

### 캡처가 검은 화면이거나 비어 있습니다

macOS 화면 기록 권한을 확인합니다. `시스템 설정` > `개인정보 보호 및 보안` > `화면 기록`에서 Shotta를 허용한 뒤 앱을 다시 실행합니다.

### 요소 캡처가 아무것도 선택하지 못합니다

손쉬운 사용 권한을 확인합니다. 일부 앱은 접근성 정보를 제한할 수 있으며, 비밀번호 입력칸 같은 보안 입력 영역은 캡처 대상으로 잡히지 않을 수 있습니다.

### 단축키가 반응하지 않습니다

설정의 단축키 탭에서 현재 단축키를 확인합니다. 다른 앱이 같은 전역 단축키를 먼저 사용 중이면 Shotta가 해당 단축키를 등록하지 못할 수 있습니다.

### 권한을 계속 다시 요청합니다

개발 빌드나 ad-hoc 서명 앱은 재빌드할 때 macOS가 다른 앱으로 인식할 수 있습니다. 같은 번들 ID와 같은 코드서명 identity로 만든 `Shotta.app`을 계속 실행하면 권한 재승인이 줄어듭니다.

### 앱을 완전히 종료하고 싶습니다

상단바 Shotta 아이콘을 클릭한 뒤 `종료`를 선택합니다. 에디터 창만 닫아도 Shotta는 상단바에서 계속 실행됩니다.
