# Shotta ユーザーガイド

Shotta は macOS のメニューバーで動作するスクリーンショットツールです。画面全体、範囲、ウィンドウ、表示中の UI 要素を撮影し、エディタで編集したり PNG ファイルとして保存したりできます。

## 画像ファイルと別名で保存

**ファイル > 画像を開く…**（Command+O）、メニューバー、Finderの**このアプリケーションで開く > Shotta**、またはエディタへのファイルドロップで、PNG・JPEG・WebP・HEIC/HEIF・TIFF・BMP・GIFを開けます。複数ファイルは順番に履歴へ追加されます。アニメーションや複数ページの画像は最初のフレームまたはページのみ開きます。6400万ピクセルまたはデコードデータ256MiBを超える画像は開けません。ファイルを開く際に画面収録権限は不要で、キャプチャの自動保存も実行しません。

**ファイル > 別名で保存…**（Shift+Command+S）、または保存ボタンの右クリックで、保存先・ファイル名・PNG/JPEG/TIFF/HEIC/BMP形式を指定できます。PNGとTIFFは透明度を保持し、JPEG・HEIC・BMPは白い背景で保存します。WebPは読み込みのみ対応します。既存ファイルの置き換えはシステムが確認します。

Command+Sと保存ボタンの通常クリックは、設定されたフォルダに新しいPNGを保存します。読み込みでは元ファイルを変更しません。別名で保存で元ファイルを選び、置き換えを確認した場合のみ元ファイルを更新します。


## はじめに

1. `Shotta.app` を起動します。
2. macOS メニューバーの右側に Shotta アイコンが表示されていることを確認します。
3. 初回キャプチャ時に macOS が画面収録権限を求めたら許可します。
4. 要素キャプチャでアクセシビリティ権限の案内が表示されたら、`システム設定を開く` を選択して Shotta を許可します。

初回起動時に macOS が「検証できないアプリ」という警告で起動をブロックした場合は、`システム設定` > `プライバシーとセキュリティ` を開き、`このまま開く` をクリックしてください。詳細は [README](../README.md) を参照してください。

Shotta はメニューバーアプリです。起動しても大きなメインウィンドウはすぐには開きません。メニューバーまたはグローバルショートカットから撮影を開始します。

## 基本的なキャプチャ

メニューバーの Shotta アイコンをクリックすると、次のコマンドを使用できます。

| メニュー | 既定のショートカット | 動作 |
| --- | --- | --- |
| 範囲キャプチャ | `Control + Option + Shift + 4` | ドラッグした長方形の範囲を撮影します。 |
| フルスクリーンキャプチャ | `Control + Option + Shift + 3` | クリックしたディスプレイを撮影します。 |
| ウィンドウキャプチャ | `Control + Option + Shift + 5` | ポインタ下でハイライトされたウィンドウを撮影します。 |
| 要素キャプチャ | `Control + Option + Shift + 6` | ポインタ下でハイライトされた UI 要素を撮影します。 |

キャプチャオーバーレイが開いているときの操作です。

| キーまたは操作 | 説明 |
| --- | --- |
| `Space` | フルスクリーン、範囲、ウィンドウ、要素の順にモードを切り替えます。 |
| `Esc` | キャプチャをキャンセルしてオーバーレイを閉じます。 |
| ドラッグ | 範囲キャプチャモードで撮影範囲を指定します。 |
| クリック | フルスクリーン、ウィンドウ、要素キャプチャモードで現在ハイライトされている対象を撮影します。 |

複数ディスプレイ環境では、すべてのディスプレイ上にオーバーレイが表示されます。フルスクリーンキャプチャはクリックしたディスプレイを対象にし、範囲キャプチャはディスプレイ境界をまたいでドラッグできます。

## 要素キャプチャの権限

要素キャプチャは、ボタン、入力欄、リスト行など、ポインタ下の UI 要素を検出するために macOS のアクセシビリティ権限を使用します。

権限がない場合、Shotta は権限案内を表示します。`システム設定を開く` を選択し、`プライバシーとセキュリティ` > `アクセシビリティ` で Shotta を許可してください。権限付与後も要素がハイライトされない場合は、Shotta を終了して再起動します。

要素キャプチャは、現在画面に表示されているアクセシビリティ要素の範囲を撮影します。画面外にスクロールしないと見えない Web ページ全体や DOM 要素全体を自動でつなぎ合わせる機能ではありません。

## キャプチャ後の動作

既定では、キャプチャが完了するとエディタウィンドウが開きます。設定でキャプチャ後の動作をクリップボードへ直接コピーするように変更できます。この場合、Shotta はキャプチャ結果をコピーし、短い完了メッセージを表示します。

メニューバーメニューの `エディタを開く` を選択すると、最後のキャプチャまたは現在のエディタを再度開けます。

## エディタ

ツールバーからツールを選んで画像を編集します。ツールバーは設定で左側、上部、下部のいずれかに配置できます。

| ツール | 説明 |
| --- | --- |
| コピー | 現在の編集結果をクリップボードへコピーします。 |
| 保存 | 現在の編集結果を PNG ファイルとして保存します。 |
| 取り消し / やり直し | 編集操作を戻す、または再適用します。 |
| 選択 | 既存の注釈を選択、移動、サイズ変更します。 |
| 四角形 / 楕円 / 矢印 / 線 | 画像上に図形を描画します。 |
| ペン | フリーハンドの線を描きます。 |
| ハイライト | ハイライトを追加します。 |
| テキスト | 画像上にテキストを追加します。 |
| 切り抜き | 選択した範囲だけを残します。 |
| ぼかし | 選択した範囲にぼかしまたはモザイクを適用します。 |

選択中のツールやオブジェクトに応じて、色、線の太さ、文字サイズ、効果の種類、効果の強さを調整できます。コピーまたは保存すると、現在表示されている編集結果が反映されます。

## テキスト認識表示

選択ツールが有効なとき、Shotta は現在のキャプチャ内のテキストを認識します。画像上のテキストをドラッグして選択し、`Command + C` を押すと、画像の代わりに選択したテキストがコピーされます。`Esc` を押すか別のツールに切り替えると、テキスト選択は解除されます。

テキスト認識はすべてデバイス上で処理されます。何も選択できない場合は、キャプチャに認識可能なテキストが含まれていない可能性があります。

## エディタのショートカット

| ショートカット | 動作 |
| --- | --- |
| `Command + C` | 編集結果をコピー |
| `Command + S` | 編集結果を保存 |
| `Command + Z` | 取り消し |
| `Command + Shift + Z` または `Command + Y` | やり直し |
| `Command + +` | 拡大 |
| `Command + -` | 縮小 |

| `Esc` | 現在のツールまたは選択操作をキャンセル |
| `Return` | 切り抜き選択を確定 |
| `Delete` | 選択した注釈を削除 |
| `Command + A` | すべての注釈を選択 |
| `Command + W` | エディタウィンドウを閉じる |
| `Command + ,` | 設定を開く |

ツール選択ショートカットです。

| キー | ツール |
| --- | --- |
| `R` | 四角形 |
| `O` | 楕円 |
| `A` | 矢印 |
| `D` | ペン |
| `H` | ハイライト |
| `T` | テキスト |
| `C` | 切り抜き |
| `B` | ぼかし |

調整ショートカットです。

| ショートカット | 動作 |
| --- | --- |
| `Option + +` | 選択中の線の太さ、またはぼかし強度を上げる |
| `Option + -` | 選択中の線の太さ、またはぼかし強度を下げる |

## 履歴

エディタの履歴パネルには、最近のキャプチャが最大 100 件まで保持されます。サムネイルをクリックすると、以前のキャプチャへ切り替えられます。

履歴パネルが開いているときは、次の操作を使用できます。

| 操作 | 説明 |
| --- | --- |
| `Option + Up` | 新しいキャプチャへ移動 |
| `Option + Down` | 古いキャプチャへ移動 |
| `Option + マウスホイール` | 履歴項目を移動 |
| サムネイルを右クリック | 画像コピー、保存場所を表示、削除メニューを表示 |

保存済みファイルがある履歴項目では、右クリックメニューから保存場所を表示できます。

## 設定

メニューバーの Shotta アイコン、または `Command + ,` から設定を開きます。

### 一般

| 項目 | 説明 |
| --- | --- |
| スクリーンショットフォルダ | 保存と自動保存に使う既定フォルダです。 |
| 自動保存 | キャプチャごとに PNG ファイルを自動保存します。 |
| ログイン時に起動 | macOS へのログイン時に Shotta を自動起動します。 |
| 言語 | 英語、韓国語、中国語、日本語から選択します。 |
| キャプチャ後の動作 | エディタを開くか、クリップボードへ直接コピーするかを選択します。 |
| ツールバー位置 | エディタツールバーを左側、上部、下部に配置します。 |

自動保存ファイル名は `shotta-YYYYMMDD-HHMM.png` 形式です。同じ分に複数のファイルが作成されると、`shotta-YYYYMMDD-HHMM 2.png` のように番号が付きます。

### ショートカット

ショートカットタブでは、フルスクリーン、範囲、ウィンドウ、要素キャプチャのグローバルショートカットを変更できます。各ショートカット欄をクリックして新しいキーの組み合わせを入力すると保存されます。リセットボタンで既定値に戻せます。

他のアプリや macOS システムショートカットと競合する組み合わせは登録できない場合があります。ショートカットが反応しない場合は、別の組み合わせを選んでください。

## トラブルシューティング

### キャプチャが黒い、または空白になる

`システム設定` > `プライバシーとセキュリティ` > `画面収録` で Shotta を許可し、アプリを再起動してください。

### 要素キャプチャで何も選択できない

アクセシビリティ権限を確認してください。一部のアプリはアクセシビリティ情報を制限する場合があり、パスワード入力欄などの安全な入力領域はキャプチャ対象として検出できないことがあります。

### ショートカットが反応しない

設定のショートカットタブで現在のショートカットを確認してください。他のアプリが同じグローバルショートカットを先に使用している可能性があります。

### 権限を何度も求められる

開発ビルドや ad-hoc 署名のアプリは、再ビルドごとに macOS から別のアプリとして扱われることがあります。同じ bundle identifier と同じ署名 identity で作成した `Shotta.app` を使い続けると、権限の再承認を減らせます。

### Shotta を完全に終了する

メニューバーの Shotta アイコンをクリックし、`終了` を選択します。エディタウィンドウだけを閉じても、Shotta はメニューバーで実行されたままです。

## アンインストール

1. メニューバーの Shotta アイコンをクリックし、`終了` を選択します。
2. Applications フォルダから `Shotta.app` を削除します。
3. 設定も削除する場合は、ターミナルで `defaults delete com.local.Shotta` を実行します。
4. 必要に応じて、`システム設定` > `プライバシーとセキュリティ` > `画面収録` と `アクセシビリティ` から Shotta の項目を削除します。

保存または自動保存したスクリーンショットは通常の PNG ファイルとして、指定したフォルダに残ります。
