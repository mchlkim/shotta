# Shotta 产品介绍

Shotta 是一款 macOS 菜单栏截图工具，用于快速截图和轻量编辑。

刚截的屏幕、存好的图片，都能接着编辑。加上说明，遮住敏感信息，再复制或保存。所有操作都在Mac上完成。

## 可截图内容

- 选定区域
- 整个显示器
- 指针下方的窗口

## 打开图片

按Command+O，通过Finder或拖入文件，就能打开PNG、JPEG、WebP、HEIC/HEIF、TIFF、BMP和GIF。动图和多页图片只打开第一帧或第一页。

## 编辑器

编辑器提供常用的截图标注工具：

- 矩形、椭圆、箭头、直线和自由画笔
- 高亮和文本
- 裁剪
- 用模糊或马赛克遮盖敏感内容
- 实况文本：选择并拷贝截图中识别出的文字
- 撤销和重做
- 复制到剪贴板，按Command+S保存新PNG，或按Shift+Command+S选择名称、位置和PNG/JPEG/TIFF/HEIC/BMP格式
- 截图与导入图片共用历史记录

## 语言

Shotta 应用界面支持英语、韩语、中文和日语。本 public 仓库也用所有支持语言提供产品介绍和用户指南，默认语言为英语。

## 安装

打开[Shotta.dmg](../downloads/Shotta.dmg)，将Shotta拖入“应用程序”文件夹。也可以下载[ZIP版本](../downloads/Shotta.app.zip)。替换前请先退出旧版，再从“应用程序”启动Shotta，最后推出DMG。系统要求、首次打开的确认步骤和校验和检查方法见[README](../README.md)。

启动 Shotta 后，请在 macOS 菜单栏中查找 Shotta 图标。
