# Shotta 产品介绍

Shotta 是一款 macOS 菜单栏截图工具，用于快速截图和轻量编辑。

它适合经常截取界面、编写文档、提交问题、整理设计反馈或制作支持材料的用户。你可以从菜单栏或全局快捷键开始截图，只在需要时打开编辑器，并快速复制或保存最终图片。

## 可截图内容

- 选定区域
- 整个显示器
- 指针下方的窗口
- 指针下方可见的 UI 元素

元素截图使用 macOS 辅助功能信息。它会截取被检测元素当前可见的边界，不会自动拼接屏幕外的网页内容或隐藏的 DOM 内容。

## 编辑器

编辑器提供常用的截图标注工具：

- 矩形、椭圆、箭头、直线和自由画笔
- 高亮和文本
- 裁剪
- 用模糊或马赛克遮盖敏感内容
- 实况文本：选择并拷贝截图中识别出的文字
- 撤销和重做
- 复制到剪贴板或保存为 PNG
- 最近截图历史

## 语言

Shotta 应用界面支持英语、韩语、中文和日语。本 public 仓库也用所有支持语言提供产品介绍和用户指南，默认语言为英语。

## 安装

下载 [Shotta.app.zip](../downloads/Shotta.app.zip)，解压后将 `Shotta.app` 移到 Applications 文件夹。系统要求、首次启动的 Gatekeeper 步骤和校验和验证方法请参阅 [README](../README.md)。

启动 Shotta 后，请在 macOS 菜单栏中查找 Shotta 图标。
