# Shotta 製品紹介

Shotta は、すばやいスクリーンショット撮影と軽量な編集のための macOS メニューバーアプリです。

いま撮った画面も、保存してある画像も。ひと言添えて、見せたくない部分を隠したら、コピーや保存へ。すべてMacの中で処理します。

## 撮影できるもの

- 選択した範囲
- ディスプレイ全体
- ポインタ下のウィンドウ

## 画像を開く

Command+O、Finder、ファイルのドラッグ＆ドロップでPNG、JPEG、WebP、HEIC/HEIF、TIFF、BMP、GIFを開けます。アニメーションや複数ページの画像は、最初のフレームまたはページを開きます。

## エディタ

エディタには、スクリーンショット注釈でよく使う機能があります。

- 四角形、楕円、矢印、線、フリーハンドペン
- ハイライトとテキスト
- 切り抜き
- 機密情報を隠すぼかしとモザイク
- テキスト認識表示: キャプチャ内のテキストを選択してコピー
- 取り消しとやり直し
- クリップボードへコピー、Command+Sで新しいPNGを保存、Shift+Command+Sで名前・保存先・PNG/JPEG/TIFF/HEIC/BMP形式を選択
- 最近のキャプチャと読み込んだ画像をまとめた履歴

## 言語

Shotta のアプリ UI は英語、韓国語、中国語、日本語に対応しています。この public リポジトリでも、製品紹介とユーザーガイドをすべての対応言語で提供します。既定の言語は英語です。

## インストール

[Shotta.dmg](../downloads/Shotta.dmg)を開き、Shottaをアプリケーションフォルダにドラッグしてください。[ZIP版](../downloads/Shotta.app.zip)も用意しています。旧バージョンを終了してから置き換え、アプリケーションフォルダから起動します。インストール後はDMGを取り出してください。システム要件、初回起動の承認、チェックサムの確認は[README](../README.md)をご覧ください。

Shotta を起動したら、macOS のメニューバーに Shotta アイコンが表示されていることを確認します。
