# Shotta 製品紹介

Shotta は、すばやいスクリーンショット撮影と軽量な編集のための macOS メニューバーアプリです。

UI、ドキュメント、バグ報告、デザインメモ、サポート資料を繰り返し作成する人向けに設計されています。メニューバーまたはグローバルショートカットから撮影を開始し、必要なときだけエディタを開いて、結果をすばやくコピーまたは保存できます。

## 撮影できるもの

- 選択した範囲
- ディスプレイ全体
- ポインタ下のウィンドウ
- ポインタ下の表示中の UI 要素

要素キャプチャは macOS のアクセシビリティ情報を使用します。検出された要素の現在表示されている範囲を撮影しますが、画面外の Web ページや非表示の DOM コンテンツを自動でつなぎ合わせる機能ではありません。

## エディタ

エディタには、スクリーンショット注釈でよく使う機能があります。

- 四角形、楕円、矢印、線、フリーハンドペン
- ハイライトとテキスト
- 切り抜き
- 機密情報を隠すぼかしとモザイク
- 取り消しとやり直し
- クリップボードへコピー、または PNG として保存
- 最近のキャプチャ履歴

## 言語

Shotta のアプリ UI は英語、韓国語、中国語、日本語に対応しています。この public リポジトリでも、製品紹介とユーザーガイドをすべての対応言語で提供します。既定の言語は英語です。

## インストール

[GitHub Releases](../../releases) から Shotta をダウンロードし、リリースパッケージを開いて、案内が表示された場合は `Shotta.app` を Applications フォルダへ移動してください。

Shotta を起動したら、macOS のメニューバーに Shotta アイコンが表示されていることを確認します。
