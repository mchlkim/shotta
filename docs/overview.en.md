# Shotta Overview

Shotta is a macOS menu bar app for fast screenshot capture and lightweight editing.

Capture a screen or open an image you already have. Add a note, hide sensitive details, and copy or save the result, all on your Mac.

## What You Can Capture

- A selected region
- A full display
- A window under the pointer

## Open an image

Open PNG, JPEG, WebP, HEIC/HEIF, TIFF, BMP, and GIF with Command+O, Finder, or file drop. Animated and multipage files open at the first frame or page.

## Editor

The editor supports common screenshot annotation tasks:

- Rectangles, ellipses, arrows, lines, and freehand pen
- Highlights and text
- Crop
- Blur and mosaic for sensitive content
- Live Text: select and copy text recognized inside the capture
- Undo and redo
- Copy to clipboard, save a new PNG with Command+S, or choose a name, folder, and PNG/JPEG/TIFF/HEIC/BMP format with Shift+Command+S
- Recent capture and imported-image history

## Languages

Shotta supports English, Korean, Chinese, and Japanese in the app UI. This public repository provides product information and user guides in all supported languages, with English as the default.

## Installation

Download [Shotta.dmg](../downloads/Shotta.dmg), open it, and drag Shotta to Applications. A [ZIP download](../downloads/Shotta.app.zip) is also available. Quit the old copy before replacing it, then launch Shotta from Applications and eject the DMG. Requirements, first-launch approval, and checksum checks are in the [README](../README.md).

When you launch Shotta, look for the Shotta icon in the macOS menu bar.
