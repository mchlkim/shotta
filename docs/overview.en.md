# Shotta Overview

Shotta is a macOS menu bar app for fast screenshot capture and lightweight editing.

It is designed for people who repeatedly capture UI, documentation, bugs, design notes, and support material. Shotta keeps the capture controls close at hand, opens the editor only when needed, and lets you copy or save the final image quickly.

## What You Can Capture

- A selected region
- A full display
- A window under the pointer
- A visible UI element under the pointer

Element capture uses the macOS Accessibility tree. It captures the visible bounds of the detected element; it does not stitch hidden or off-screen webpage content.

## Editor

The editor supports common screenshot annotation tasks:

- Rectangles, ellipses, arrows, lines, and freehand pen
- Highlights and text
- Crop
- Blur and mosaic for sensitive content
- Undo and redo
- Copy to clipboard or save as PNG
- Recent capture history

## Languages

Shotta supports English, Korean, Chinese, and Japanese in the app UI. This public repository provides product information and user guides in all supported languages, with English as the default.

## Installation

Download [Shotta.app.zip](../downloads/Shotta.app.zip), unzip it, and move `Shotta.app` to your Applications folder.

When you launch Shotta, look for the Shotta icon in the macOS menu bar.
