# Shotta 제품 소개

Shotta는 빠른 스크린샷 캡처와 간단한 편집을 위한 macOS 상단바 앱입니다.

방금 캡처한 화면도, 저장해 둔 이미지도. 설명을 더하고 민감한 부분은 가린 뒤 필요한 곳에 복사하거나 저장하세요. 모든 작업은 Mac 안에서 처리합니다.

## 캡처 대상

- 선택한 영역
- 전체 디스플레이
- 커서 아래의 창

## 이미지 파일 열기

Command+O, Finder 또는 파일 드롭으로 PNG, JPEG, WebP, HEIC/HEIF, TIFF, BMP, GIF를 엽니다. 움직이는 이미지와 여러 페이지 이미지는 첫 프레임이나 페이지만 엽니다.

## 에디터

에디터는 스크린샷 주석 작업에 필요한 기본 도구를 제공합니다.

- 사각형, 원, 화살표, 선, 펜
- 하이라이트와 텍스트
- 자르기
- 민감한 영역을 가리는 흐림과 모자이크
- 라이브 텍스트: 캡처 이미지 속 텍스트를 선택하고 복사
- 실행 취소와 다시 실행
- 클립보드 복사, Command+S로 새 PNG 저장, Shift+Command+S로 이름·위치·PNG/JPEG/TIFF/HEIC/BMP 형식 선택
- 최근 캡처와 가져온 이미지를 함께 보는 히스토리

## 언어

Shotta 앱 UI는 영어, 한국어, 중국어, 일본어를 지원합니다. 이 public 저장소의 제품 소개와 사용자 가이드도 모든 지원 언어로 제공합니다. 기본 언어는 영어입니다.

## 설치

[Shotta.dmg](../downloads/Shotta.dmg)를 열어 Shotta를 응용 프로그램 폴더로 옮기세요. [ZIP 다운로드](../downloads/Shotta.app.zip)도 제공합니다. 기존 앱을 먼저 종료하고 교체한 뒤 응용 프로그램 폴더에서 실행하세요. DMG는 설치 후 추출하면 됩니다. 시스템 요구사항, 첫 실행 승인, 체크섬 확인 방법은 [README](../README.md)에 있습니다.

Shotta를 실행하면 macOS 상단바에 Shotta 아이콘이 표시됩니다.
