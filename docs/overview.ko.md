# Shotta 제품 소개

Shotta는 빠른 스크린샷 캡처와 간단한 편집을 위한 macOS 상단바 앱입니다.

UI 캡처, 문서 작성, 버그 리포트, 디자인 피드백, 지원 자료를 자주 만드는 사용자를 위해 만들었습니다. 캡처는 상단바와 전역 단축키에서 바로 시작하고, 필요한 경우에만 에디터를 열어 결과를 빠르게 복사하거나 저장할 수 있습니다.

## 캡처 대상

- 선택한 영역
- 전체 디스플레이
- 커서 아래의 창
- 커서 아래의 보이는 UI 요소

요소 캡처는 macOS 손쉬운 사용 정보를 사용합니다. 감지된 요소의 현재 보이는 영역을 캡처하며, 화면 밖의 웹페이지나 숨겨진 DOM 콘텐츠를 자동으로 이어 붙이지는 않습니다.

## 에디터

에디터는 스크린샷 주석 작업에 필요한 기본 도구를 제공합니다.

- 사각형, 원, 화살표, 선, 펜
- 하이라이트와 텍스트
- 자르기
- 민감한 영역을 가리는 흐림과 모자이크
- 라이브 텍스트: 캡처 이미지 속 텍스트를 선택하고 복사
- 실행 취소와 다시 실행
- 클립보드 복사 또는 PNG 저장
- 최근 캡처 히스토리

## 언어

Shotta 앱 UI는 영어, 한국어, 중국어, 일본어를 지원합니다. 이 public 저장소의 제품 소개와 사용자 가이드도 모든 지원 언어로 제공합니다. 기본 언어는 영어입니다.

## 설치

[Shotta.app.zip](../downloads/Shotta.app.zip)을 다운로드해 압축을 푼 뒤 `Shotta.app`을 Applications 폴더로 옮기세요. 시스템 요구사항, 첫 실행 시 Gatekeeper 안내, 체크섬 확인 방법은 [README](../README.md)를 참고하세요.

Shotta를 실행하면 macOS 상단바에 Shotta 아이콘이 표시됩니다.
